# Script Breakdown and Visual References

## Read the whole script before you break it down

- Read the full script first, including stage directions and dialogue, and note the total scene count and the running order before you write anything.

- Split the script into scenes or segments and keep the script's own numbering when it has one, and flag any numbering gap or duplicate instead of silently renumbering.

- Write one short line per scene that says what happens and what the scene does for the story, in plain words the reader can skim.

- List the characters in each scene with their state in that scene, such as awake or asleep, standing or sitting, and entering or leaving, so later shot work can keep those states continuous.

## Pair each scene with picture references

- Search for real photographs and real film stills that match each scene's composition, light and colour.

- Use only real images with a named source, and never present an AI generated image as a reference still.

- Keep two personal libraries and consult both for every scene. The first is a film stock colour table that records each stock's colour traits, the scenes it suits and a ready to paste prompt fragment in each working language. The second is an aesthetic source library of photographers and films whose composition, light and colour methods you have studied.

- Name the stock, the photographer or the film a borrowing comes from when you reuse one of its methods, so the choice stays traceable.

- Give each scene a small set of strong references rather than a long pile, and say in one line what each reference is there to teach, such as a framing, a light direction or a colour pairing.

## Set the tone direction per scene

- Describe the tone in shootable terms, covering light direction and hardness, how clear the light and dark split is, the warm and cold balance, and the saturation level.

- Write generation prompts in this order when a scene needs one, covering space density first, then composition, then one main light source, then still and moving elements apart, then grain and halation, and end the prompt with an Avoid list.

- State the intended aspect ratio and shot approach with the tone note.

- Mark any fact you could not verify as unverified instead of stating it flatly, and drop a reference whose source you cannot name.

## Deliver the breakdown

- Save the breakdown as a document in the project's own folder, with one block per scene holding the story line, the characters and states, the references with sources, and the tone direction.

- Send a short summary with the document that names the scene count, the references found and any scene where references are thin.

- Save any new reference standard or settled tone choice into the matching library so the next script starts from it instead of from scratch.

## Alternatives for better results

- Break down one act or one location first and let the director react to the reference taste before you finish the whole script, when the script is long and the look is not yet settled.

- Reuse a reference set that already worked for an earlier scene with the same location and light instead of searching again.
