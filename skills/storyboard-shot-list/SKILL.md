# Storyboard and Shot List

## Build the table shot by shot

- Give every shot its own row with a shot number, a duration in seconds, one shot size, the camera position, the action, the expression, and the sound or subtitle note for that shot.

- Keep one shot size per shot and change shot size only by cutting to the next shot.

- Keep the camera fixed or allow only a very slow micro move, and do not plan a push, a pull, a pan across several framings or a one take.

- Add the durations up and state the total running time with the table, and flag it before production when the total runs past the target length.

## Write expression and state into every shot

- Write the exact facial expression each character needs in that shot and tie it to the story beat, so an impact or fright shot asks for a pained or startled face in words and not only the action.

- Write each character's body state into the shot, such as asleep or awake and sitting or standing, and keep that state continuous with the shots before and after it.

- Keep left and right positions continuous across shots, and note the screen side of each character in the row so a later generation or edit can be checked against it.

- Mark any time jump between shots in the table itself, so a state change across the jump does not read as a continuity error.

## Write generation prompts from the table

- Write one prompt per shot from its row, and feed the locked character reference image for every character in the shot instead of relying on text alone.

- State the intended aspect ratio and resolution in the plan, and keep reference images in the same orientation as the intended output.

- Lock the fixed traits in words in each prompt, covering head to body proportion, ear shape, markings and colours, so a character design cannot drift between shots.

- Report the new plan and the exact prompt changes and wait for confirmation before you regenerate a shot that was already generated once.

## Check the table and the footage before delivery

- Check the table against the script scene by scene and confirm that no story beat, prop or character entrance is missing.

- Check every produced shot against its row for shot size, camera speed, expression, body state and left and right position, and name any mismatch plainly before you offer a fix.

- Check the produced shots for clipping, duplicated characters and extra limbs, and compare each character against its reference for face, markings and proportions.

- Send the table as a file in the project folder together with a short note on total length, shot count and anything that still needs a decision.

## Alternatives for better results

- Storyboard the opening three shots and produce a test from them first when a new look or a new character design has not yet been proven on screen.

- Reuse the shot layout of a proven earlier scene when the new scene repeats the same action in the same place.
